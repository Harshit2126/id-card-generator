# ID Card Generator

A simple web-based ID Card Generator built using **HTML, CSS, and JavaScript**.

The project allows users to enter their name and ID, upload a photo, and see the information displayed dynamically on a customizable ID card.

## 🚀 Features

* Enter a user's name
* Enter a custom ID
* Upload a photo from the device
* Live preview of the ID card
* Automatically updates the card when information is entered
* Customizable card styling using CSS
* Responsive and simple user interface

## 🛠️ Technologies Used

* **HTML5** — Page structure and content
* **CSS3** — Styling, layout, colors, gradients, and card design
* **JavaScript** — Dynamic content and image upload functionality
* **File API** — Reading the uploaded image in the browser

## 🎯 How It Works

The application uses HTML to create the input fields and ID card structure.

CSS is used to design the card and control its appearance.

JavaScript connects the input fields to the card and updates the displayed information in real time.

For example:

```text
User enters name
       ↓
JavaScript detects the input
       ↓
Card information is updated
       ↓
User's name appears on the card
```

The same approach is used to display the uploaded photo inside the card.
